# Portal Educativo Ángel Tech 💻📚

Sitio web educativo desarrollado como proyecto práctico de desarrollo web front-end, enfocado en presentar contenido tecnológico de manera clara, organizada y responsive.

## 🌐 Demo en vivo

Puedes visitar el proyecto aquí:

https://portal-educativo-angel-tech.netlify.app

## 📖 Sobre el proyecto

Portal Educativo Ángel Tech es un sitio web educativo desarrollado con HTML5 y CSS3.

El proyecto presenta información relacionada con la historia y evolución de las computadoras e integra diferentes recursos y componentes web, incluyendo navegación, imágenes, contenido multimedia, listas y un formulario de registro.

## ✨ Características

- Diseño web responsive.
- Navegación entre diferentes secciones.
- Galería de imágenes.
- Integración de contenido de audio.
- Formulario de registro.
- Organización mediante archivos HTML y CSS separados.
- Uso de estructura semántica HTML5.
- Efectos visuales y estados hover.
- Adaptación para diferentes tamaños de pantalla.

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- Responsive Web Design

## 📁 Estructura del proyecto

- `index.html` — Página principal.
- `Formulario.html` — Página de registro.
- `estilos.css` — Estilos de la página principal.
- `estilos_formulario.css` — Estilos del formulario.
- `Imagenes/` — Recursos gráficos utilizados en el proyecto.
- `Audios/` — Recursos de audio.

## 🎯 Objetivo del proyecto

Este proyecto fue desarrollado con el objetivo de fortalecer conocimientos de desarrollo web front-end, especialmente en estructura HTML, estilos CSS, organización de proyectos y diseño adaptable a diferentes dispositivos.
